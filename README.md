# Digital Dock — Assignment 3 Prototype

React + Vite prototype based on your four hand-drawn wireframes.

## Run it
1. Install Node.js LTS from https://nodejs.org/
2. Extract this folder and open it in VS Code.
3. In the terminal run `npm install` then `npm run dev`.
4. Open the local URL shown in the terminal (usually http://localhost:5173).

## Included
- Home page with search and three channel cards
- Channel page with category filters and original-source links
- Submission form with URL validation and pending-review demo state
- Admin dashboard with approve/reject demo actions
- About, Rules and Contact pages

## Limitations
This is a front-end prototype. Data resets on refresh; no real login, database, server-side URL safety checks, CAPTCHA, domain trust verification or secure admin authorization is implemented. Admin actions are a demonstration only. State this accurately in Assignment 3.
